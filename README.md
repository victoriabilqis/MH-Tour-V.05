# MH Tour V8.0.5 Android — Verified Install Build

Native Android Gradle project. The Android application module is `app/`; a separate
`android/` folder is not required.

GitHub Actions builds a debug-signed APK and verifies it with `zipalign` and
`apksigner` before publishing it.

Install only `MH-Tour-V8.0.5-Android-Install.apk` from the artifact
`MH-Tour-V8.0.5-Android-Verified`.
